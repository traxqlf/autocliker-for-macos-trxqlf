# 🖱️ macOS AutoClicker

Un outil d'auto-clic moderne, léger et ultra-rapide développé en **Swift** et **SwiftUI**, conçu exclusivement pour macOS.

---

## 📥 Téléchargement (Download)
Vous ne souhaitez pas compiler le code ? Téléchargez directement la dernière version stable :
* **[👉 Télécharger le .dmg (v1.0)](https://github.com/traxqlf/autocliker-for-macos-trxqlf/releases/latest)** *(Glissez l'application dans votre dossier Applications)*

---

## ✨ Fonctionnalités
* 🌟 Interface utilisateur fluide et moderne en SwiftUI.
* ⚡ Paramètres d'intervalle de clics ajustables en temps réel.
* 🍃 Ultra-léger : faible consommation de ressources système.

## 🛠️ Prérequis (Pour les développeurs)
Pour compiler et exécuter ce projet depuis le code source :
* macOS 14 (Sonoma) ou version supérieure.
* **Xcode** (dernière version conseillée).
   ```bash
  	1.	Ouvrir le projet :
        Ouvrez le dossier cloné et double-cliquez sur le fichier Xcode du projet.
	2.	Lancer l'application :
        Dans Xcode, appuyez sur le bouton Play (ou Cmd + R) pour compiler et lancer l'application.
